# Start guide

Download `start-guide.html` and open it in Chrome. It has copy buttons for every command.

- **Every time:** open Docker Desktop → check `docker ps` → open n8n → run the warm-up test
- **Switching off:** `docker stop ngrok`, then quit Docker Desktop
- **Quick fixes** for the common errors
- **First-time setup** if you ever move to a new laptop

`demo-runbook.md` has the 5-minute demo order, the 2-minute pitch and likely interview questions.

- `sticky-notes.md` – ready-to-paste notes that label every n8n canvas (with the website and chatbot links)
- `updating-data.md` – how to edit, add or replace the data for the live tools and for the website
- `demo-walkthrough.html` – the testing walkthrough: which connectors to turn on, messages to copy into Claude with sample answers, questions and answers, website checks and chatbot questions
