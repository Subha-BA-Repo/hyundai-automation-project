How to switch the project on

Everything runs free on your own laptop. Follow the green section every time you want to show the project. Use the blue section only if you ever set it up again on a new or reset laptop.

Every time · about 5 minutes

Start the project

Your laptop already has everything installed. You only need to wake it up.

  1. Plug in the charger and stop the laptop from sleepingWindows Settings → System → Power → set "When plugged in, put my device to sleep after" to Never. If the laptop sleeps, the project goes offline.
  2. Open Docker DesktopFind it in the Start menu. Wait until the bottom-left corner says Engine running (green). This usually takes under a minute. Docker Desktop is the app that keeps n8n (your automation tool) and ngrok (your public web address) running.
  3. Check that both parts are runningOpen Windows PowerShell from the Start menu, paste this and press Enter:
    docker ps
    two lines in the list, one named n8n and one named ngrok, both saying "Up".
    If one is missing, paste this and press Enter, then run docker ps again:
    docker start n8n docker start ngrok
  4. Open n8nOpen Chrome and go to http://localhost:5678. Sign in with your n8n email and password.
    your five workflows: two "MCP" ones, two "Tool" ones and "Chat – Hub Bot", each marked Published.
  5. Run the warm-up testDo these three quick checks so nothing is "cold" when you present:
    CheckWhat to doGood result
    ChatbotOpen the chatbot link (see Changing the dataYour links) and ask "Which defect is most urgent?"Mentions DCT judder, 16 reports
    ClaudeNew Cowork task with the Hyundai plugin on: "Triage this: Exter ka AC bilkul thanda nahi karta, service center ne kuch nahi kiya."English translation, AC & Cooling, Service Engineering
    WebsiteOpen the Customer Voice Hub link, click "Chat with the bot", ask one question and click AllowAn answer appears in the chat window
When you are done

Switch off

  1. Close the public address (recommended)This stops anyone outside reaching your laptop. Paste in PowerShell:
    docker stop ngrok
    Next time, docker start ngrok brings it back with the same address.
  2. Quit Docker DesktopRight-click the whale icon near the clock and choose Quit Docker Desktop. Your workflows stay saved.
If something goes wrong

Quick fixes

What you seeWhat it meansWhat to do
"This page isn't working" at localhost:5678n8n is not runningOpen Docker Desktop, wait for Engine running, then run docker start n8n and wait 30 seconds
"Bad gateway" or "endpoint offline" on the ngrok addressThe public address is not connected to n8nRun docker restart ngrok, wait 10 seconds and refresh
Chatbot says "Error in workflow"Google's AI was busy for a momentWait one minute and ask once. In n8n, the Executions tab shows the exact reason
Chatbot takes more than 30 secondsThe AI model is too heavy or busyIn "Chat – Hub Bot", open the Google Gemini node and choose the "Flash-Lite" model, then Publish
Claude says it can't reach the Hyundai toolsDocker or ngrok is offDo steps 2–3 of "Start the project"
Gemini error "model not found" or "no longer available"Google retired that modelOpen each Google Gemini node and pick the newest Flash model in the list, then Publish
ngrok error "authentication failed"The ngrok key is wrong or was resetFollow step 4 of the first-time setup with your current key

First-time setup on a new or reset laptop

Skip this if the project already starts with the green section. Everything here is free and needs no card.

  1. Install Docker DesktopDownload it from docker.com, install with the default options and restart the laptop. Open it and wait for Engine running.
  2. Create a storage box and a private networkThe storage box keeps your workflows safe. The private network lets n8n and ngrok talk to each other. Paste in PowerShell:
    docker volume create n8n_data docker network create hcv-net
  3. Start n8nPaste this as one line:
    docker run -d --name n8n --network hcv-net -p 5678:5678 --restart unless-stopped -e GENERIC_TIMEZONE="Asia/Kolkata" -e TZ="Asia/Kolkata" -e WEBHOOK_URL=https://lumpish-character-reload.ngrok-free.dev/ -e N8N_PROXY_HOPS=1 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
    Wait about 30 seconds, then open http://localhost:5678 and create your n8n account (it stays on your laptop).
  4. Start ngrok (your fixed public address)Sign in at dashboard.ngrok.com, open Your Authtoken, click the eye icon and copy it. Put it between the quotes below. Never share this key.
    $env:NGROK_TOKEN = "PASTE_YOUR_NGROK_KEY_HERE"
    Then paste this exactly as it is:
    docker run -d --name ngrok --network hcv-net --restart unless-stopped -e NGROK_AUTHTOKEN=$env:NGROK_TOKEN ngrok/ngrok:latest http http://n8n:5678 --url=https://lumpish-character-reload.ngrok-free.dev
    opening https://lumpish-character-reload.ngrok-free.dev shows the n8n sign-in page (click "Visit Site" first if ngrok shows a notice).
  5. Put the sample data onlineUpload the two files from the 05-sample-data folder to Google Drive and open each with Google Sheets. In each sheet: File → Share → Publish to web → choose "Comma-separated values (.csv)" → Publish. Copy both links and change the ending to pub?output=csv.
  6. Add your Google AI key to n8nGet a free key at aistudio.google.com/apikey. In n8n: Personal → Credentials → Create → "Google Gemini (PaLM) API" → paste the key → Save.
  7. Bring in the five workflowsIn n8n, for each file in the 03-n8n-workflows folder: Create workflow → the "⋯" menu at the top → Import from file. Import in this order:
    OrderFileAfter importing
    1Tool – Score ReviewChoose your Gemini key in the Gemini node, then Publish
    2Tool – Escalation RadarPaste your tickets sheet link into the HTTP Request node, then Publish
    3MCP 1 – Review IntelligenceOpen the tool node, re-select "Tool – Score Review" from the list, then Publish
    4MCP 2 – Service Escalation RadarRe-select "Tool – Escalation Radar", then Publish
    5Chat – Hub BotChoose your Gemini key, re-select both tools, then Publish. Copy the new Chat URL from the first node
    Importing gives each workflow a new internal number, which is why the tool nodes need re-selecting. The chatbot link also changes, so update your bookmark.
  8. Connect ClaudeIn Claude: Settings → Plugins → add the file 06-claude-plugin/hyundai-customer-voice.plugin. It brings the five skills and both Hyundai tools. If tools show twice, remove the older copies under Settings → Connectors.
  9. TestRun the three checks in step 5 of "Start the project". You are done.
