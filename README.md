# Hyundai Automation Project · Customer Voice Hub

An AI assistant and automation setup for an after-sales quality team. It reads customer complaints (English, Hindi or Hinglish), finds repeated faults across many customers, ranks open service cases by risk, and drafts the follow-up for the right team.

Built by **Subha Das** (MBA Business Analytics, Chandigarh University) for the AI For All 2.0 Cowork capstone and the Hyundai Motor India Management Trainee interview.

> Demo project with synthetic data. Not affiliated with or endorsed by Hyundai Motor India.
