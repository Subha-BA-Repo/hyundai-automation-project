# Sample data (synthetic)

- `hyundai_customer_reviews_SYNTHETIC.csv` – 180 reviews, Jul–Oct 2026, 8 models, 10 cities
- `hyundai_service_tickets_SYNTHETIC.csv` – 86 service tickets with status, days open, repeat visits and safety flag

All rows are made up for demonstration. Patterns were built in on purpose (for example gearbox judder on DCT cars, sunroof leaks, weak AC on the Exter) so the tools have something real to find.
